# 🌐 Hypenest - Protótipo de Rede Social com React e Sass

This repository contains a **React-based prototype of a social media platform**, refactored from a previous version initially built with **HTML**, **CSS**, and **Vanilla JavaScript** in [https://gui-silva-github.github.io/socialMedia/]. The goal was to rebuild the project **from scratch** using a **modern React workflow**, featuring **Hooks**, **component-based architecture**, and **Sass** for better styling management and scalability.

<hr>

## 🎯 Recursos

- Modular and reusable React components
- Component-level styling with **Sass (SCSS)**
- Basic user post simulation (no backend yet)
- Responsive layout using Flexbox and media queries
- Clear separation of UI logic and structure

## 📌 Objetivos do Projeto

- Learn and apply React Hooks
- Convert a static HTML/JS/CSS project into a dynamic React SPA
- Practice .sass modularization and reusable design patterns
- Lay the groundwork for future enhancements (e.g. authentication, backend integration)

## 🛠️ Usando localmente

1. Clone the repository:

```bash
git clone https://github.com/gui-silva-github/hypenest.git
```

2. Change directory:

```bash
cd hypenest
```

3. Install dependencies and run:

```bash
npm install
npm run dev
```
